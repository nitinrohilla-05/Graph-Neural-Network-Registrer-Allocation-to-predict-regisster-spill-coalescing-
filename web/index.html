GNN Register Allocation & Spill Coalescing Theory

Multi-Relational Graph Formulation

The compiler program is modeled as a multi-relational graph $G = (V, E_{\text{interf}}, E_{\text{coal}})$. Interference Edges enforce non-conflicting physical register assignments ($c_u \ne c_v$), while Coalescing Edges represent move instruction affinity ($v_{\text{dst}} \leftarrow v_{\text{src}}$) to eliminate move overhead.

Relational GNN Architecture

Node representations are updated via a 3-layer Relational GCN: $$H^{(l+1)} = \sigma \left( H^{(l)} W_{\text{self}} + \hat{A}_{\text{interf}} H^{(l)} W_{\text{interf}} + \hat{A}_{\text{coal}} H^{(l)} W_{\text{coal}} \right)$$ Predicts physical register class $(R_0 \dots R_{K-1})$ or Spill class.

Graph Coloring Conflict Loss

Trained using Cross-Entropy combined with a differentiable soft graph coloring penalty loss: $$\mathcal{L}_{\text{conflict}} = \sum_{(u,v) \in E_{\text{interf}}} \sum_{k=0}^{K-1} P(c_u = k) \cdot P(c_v = k)$$
